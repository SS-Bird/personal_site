# Directory

There is a file, DESIGN.md, that gives instructions for organisation and asethetic. Things like colours, fonts, spacing, etc. Always defer to that for style chocies. 

There is a file, CONTENT.md, that shows the textual content that must be featured and has implications for organisation. For example, CONTENT.md will tell you what is needed in the header. 

There is a folder, OLDWEB, that shows screenshots of my previous website I made with square space. I am not trying to mimick it asethetically, but I like the way things were layed out. The screenshots do not show everthing, but they should be used for inspiration about how to integrate the photos with the text. 

There is a file, assets, that contains the photos and other graphics to use on the site. There is the subfolder, graphics, which currently only contains name_written.svg: this is my name written out by hand, I want it to stay at the top left corner always. There is another folder, sewing_photos, which will be the main content of the website.
