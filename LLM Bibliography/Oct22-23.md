A record of the AI-assisted conversation that built this project.

- **Dates:** 22–24 October 2026
- **Model:** Claude Opus 5.5 (`claude-opus-5-5`), via Claude Code in VS Code
- **Prompts:** quoted in full, exactly as typed (typos included). Where an image was attached, it is described in square brackets.
- **Responses:** summarised, not transcribed.

## State of the project

**Before the conversation:** the `fabric experiement` folder held only two files:
- `Component 1.svg`: a hand-drawn layout sketch of a fabric page with a left strip, a seam, and a folded top band with a curled corner.
- `CLAUDE.md`: the brief, empty at first and filled in after the first prompt.

The parent `Personal Site` folder already had a plain HTML/CSS sewing archive, with its own `DESIGN.md`, `CONTENT.md`, photos and graphics. No code existed for the fabric experiment.

**After the conversation:** a working Vite + Three.js + GSAP prototype of the sewing site, in which the page is fabric:
- **Two linen pieces:** a left strip and a main panel, joined by a red hand-stitched seam. Both are drawn by custom GLSL shaders: procedural linen weave, lighting from surface normals, and soft fold shadows.
- **First open:** the sheet arrives folded once, its crease is pulled up, then the inner corners fall over two bars to reveal the header.
- **Page change:** both inner corners are tugged off-screen in opposite directions (the strip down-left, the main panel down-right). The new page's fabric is pulled back in the same way, in reverse.
- **Scrolling down a page:** the right-hand flap is pushed back up until it lies flat, and falls again when you scroll back to the top.
- **Header:** sits *under* the fabric and scrolls sideways in an endless loop beneath the fabric edge. It holds the hand-written name and the six nav links.
- **Content:** all six pages of the Personal Site (Home, 1780s Ensemble, Larp!, Other Historical Pieces, Modern Pieces, Mending) with their photos. Each photo is "sewn on" with a squiggly edge thread and stitches.
- **Under the fabric:** a tiled plaid fabric scan.
- **Two themes:**
  - light: Lamont "white guard" linens on grey plaid
  - dark (default): "Dirty jewels" linens on ochre plaid
- **Fonts:** Karla and Crimson Pro. A `/fonts` page compares 25 font options.
- **Debug panel (lil-gui):** controls for every fold, animation, font and colour, including palette presets.
- **Performance:** rendering happens only on demand, pixel ratio is capped, and there's a reduced-motion fallback.
